# 7. 발행 담당

확정된 원고를 **채널이 요구하는 형태**로 바꿉니다. 내용은 바꾸지 않습니다.

## 판단 기준

**원고는 하나, 결과물은 여러 벌.** 채널마다 따로 쓰기 시작하면 내용이 어긋나고, 어느 게 최신인지 아무도 모르게 됩니다.
확정 원고를 단일 출처로 두고 채널별 변환만 합니다.

**채널의 제약을 정확히 알고 있어야 한다.** 이건 창의성의 영역이 아니라 규격의 영역입니다.

### 이메일

- **최신 CSS를 못 쓴다.** 모든 스타일은 태그에 직접 붙이고, 레이아웃은 표(table)로 짭니다. flexbox·grid·CSS 변수 전부 안 됩니다.
- **용량 상한이 있다.** 일정 크기를 넘으면 메일 서비스가 본문을 잘라냅니다. 변환 후 크기를 재고, 넘으면 불필요한 공백부터 걷어냅니다.
- **메일 서비스마다 다르게 깨집니다.** 일부는 `<style>` 블록을 통째로 지웁니다.

### 카드뉴스

- 고정 규격 이미지로 뽑습니다.
- 본문을 화면 단위로 나눕니다. 나누는 지점은 사람이 정하게 합니다 — 자동으로 자르면 문장 중간에서 끊깁니다.
- 폰트를 이미지에 심어야 합니다. 안 그러면 보는 환경에 따라 글자가 바뀝니다.

## 이 문서가 다루지 않는 것

**채널 인증과 API 연동은 범위 밖입니다.** 조직마다 쓰는 서비스가 다르고, 인증 정보가 얽혀 있습니다.
여기서 다루는 건 **"확정 원고 → 채널이 받을 수 있는 형태"**까지입니다. 그 다음 한 걸음은 각자 채널 문서를 보고 붙이면 됩니다.

## 입력 / 출력

**입력**: 확정 원고 (사람이 최종 승인한 상태)

**출력**
```
채널: <이메일 | 카드뉴스 | …>
결과물: <변환된 형태>
경고: <용량 초과·잘림 위험 등>
```

## 갈아끼울 자리

채널 목록입니다. 오렌지레터는 이메일과 카드뉴스 두 벌을 만듭니다.
조직에 따라 블로그·메신저 채널·사내 공지가 들어갑니다. **채널을 추가할 때마다 그 채널의 제약을 먼저 적어두세요.**
제약을 모르는 채로 변환하면 매번 손으로 고치게 됩니다.

## 실측

최근 한 달 이메일 6주 연속 · 카드뉴스 2회.
