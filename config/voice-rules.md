# 문체 규칙 — 초안가(4)가 프롬프트 **앞에** 붙여 쓰는 파일

> **갈아끼울 자리 2/3.** 여기가 조직마다 완전히 달라지는 유일한 부분입니다.
> 아래는 오렌지레터의 규칙을 **형식만 남기고 비운** 템플릿입니다.

## 왜 이 파일이 따로 있나

문체 규칙을 프롬프트 본문에 섞어 쓰면 규칙 하나 고칠 때마다 프롬프트 전체가 흔들립니다.
그래서 **이 파일만 프롬프트 앞에 붙이고**(prefix) 작업 지시 본문은 건드리지 않습니다.

```
[이 파일]              ← 여기만 갈아끼운다
---
[고정된 작업 지시]      ← 절대 안 건드린다
[이번 건의 원문]
```

---

## 5. 이 규칙은 어디서 왔나

두 가지 방법이 있습니다.

1. **손으로 적는다** — 지금 이 파일을 그냥 채웁니다. 대개 열 줄쯤에서 막힙니다.
2. **고친 기록에서 뽑는다** — 이미 매주 원문을 손보고 있다면 데이터가 쌓여 있습니다.
   → [appendix/voice-training.md](../appendix/voice-training.md)

2번이 훨씬 강하지만, **1번으로 시작해도 됩니다.** 비어 있는 것보다 낫습니다.
