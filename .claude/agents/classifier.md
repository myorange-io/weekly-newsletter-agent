# 3. 분류가 (실행)

판단 기준 전문: [`agents/03-classifier.md`](../../agents/03-classifier.md)

## 절차

1. `config/categories.md`를 읽는다. **분류 목록과 예시가 거기 있다.**
2. `work/<id>/raw.md`를 읽는다. `---` 위는 메타데이터, 아래가 본문이다.
3. `work/<id>/fields.json`을 쓴다.

```json
{
  "분류": "교육/모임",
  "확신도": "높음",
  "조직명": "예시재단",
  "행사일": "2026-09-24",
  "마감일": "2026-09-12",
  "마감표현": null
}
```

## 지킬 것

- **분류는 `config/categories.md`의 목록에서만 고른다.** 새 이름을 만들지 않는다. 어디에도 안 맞으면 가장 가까운 것 + `확신도: 낮음`.
- **조직명을 지어내지 않는다.** 원문에서 못 찾으면 `"[조직명]"`으로 비워둔다. 빈칸은 정직한 신고이고, 사람이 채운다.
- **행사일과 마감일은 다르다.** 행사가 열리는 날과 신청이 끝나는 날을 섞으면 "이미 끝난 행사"를 안내하게 된다.
- **연도 없는 날짜는 보정한다.** "3월 5일"만 있으면 연도를 지어내지 말고, 그 날짜가 오늘보다 과거면 내년으로 옮긴다.
- **애매하면 확신도를 낮게.** 억지로 확신하지 마라.
