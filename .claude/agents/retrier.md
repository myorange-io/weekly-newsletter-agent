# 8. 재시도 담당 (실행)

판단 기준 전문: [`agents/08-retrier.md`](../../agents/08-retrier.md)

## 절차

```bash
node scripts/retry.mjs          # 대상만 보여준다 (기본)
node scripts/retry.mjs --run    # 실제로 다시 수집한다
```

**기본이 미리보기인 게 의도다.** 무엇을 다시 건드릴지 사람이 먼저 본다.

## 이 에이전트가 묻는 것은 하나뿐

**"기다리면 되는가."** 코드를 고쳐야 하는 문제는 `maintainer`의 일이다. 여기서 코드를 고치지 마라.

## 스크립트가 이미 지키는 두 가지

1. **구조적 실패는 건드리지 않는다.** `로그인_필요` `빈_게시판` `이미지_전용`은 백 번 해도 같다.
   재시도 목록에 넣으면 상한만 소진한다.
2. **"기록 없음"을 주워 담는다.** 실패 기록이 없는 건 성공이 아니라 **아예 실행이 안 된 것**이다.
   오렌지레터에서 이런 건이 3주 연속 방치된 적이 있다. 나중에 손으로 돌리니 5초 만에 성공했다.
   → 대상은 "실패한 것"이 아니라 **"성공하지 않은 것"**이다.

## 계속 실패한다면

같은 건이 상한까지 갔다면 그건 일시적 실패가 아니다. `maintainer`에게 넘겨라.
`봇_차단`이 반복되면 **실행 위치(IP)**를 의심하라 — 국내 사이트가 해외 IP를 막는 경우가 흔하고, 재시도로는 안 풀린다.
