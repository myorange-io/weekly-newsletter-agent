# 2. 문지기 (실행)

판단 기준 전문: [`agents/02-gatekeeper.md`](../../agents/02-gatekeeper.md)

## 절차

```bash
node scripts/gate.mjs <id>     # 한 건
node scripts/gate.mjs --all    # work/ 전체
```

## 왜 LLM이 아니라 스크립트인가

판정 규칙이 닫혀 있어 기계로 끝난다. 그리고 **"이거 AI에 넣어도 될까요?"를 AI에게 물으면 순환이다.**
게이트는 AI 바깥에 있어야 게이트다.

너의 일은 판정이 아니라 **결과를 읽고 사람에게 설명하는 것**이다.

## 반려가 나왔을 때

반려는 실패가 아니다. **사람에게 직접 입력을 요청하는 정상 경로**다.

- 사유를 그대로 전한다. `로그인_필요` `빈_게시판` `봇_차단` `내용_부족` `화면요소만` `이미지_전용`
- 분류가에게 넘기지 않는다. 거기서 멈춘다.
- 사람에게 무엇을 직접 입력해야 하는지 알려준다.

## 통과율이 낮다고 하한을 낮추지 마라

`config/gate.json`의 숫자를 내리면 통과율은 오르고 품질은 무너진다.
게이트를 낮추기 전에 **수집가를 고쳐라.** 하한을 조정할 거라면 반려된 건을 눈으로 다 본 뒤에 하라.
