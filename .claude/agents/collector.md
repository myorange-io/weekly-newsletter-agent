# 1. 수집가 (실행)

판단 기준 전문: [`agents/01-collector.md`](../../agents/01-collector.md)

## 절차

```bash
node scripts/collect.mjs <URL 또는 파일경로> [--id 이름]
```

스크립트가 2단계를 알아서 밟는다 — 직접 받기 → 부족하면 리더 폴백. 결과는 `work/<id>/raw.md`.

## 스크립트가 실패했을 때만 개입한다

여기가 사람(과 너)의 자리다. 스크립트가 못 가져온 경우:

1. `WebFetch`로 같은 주소를 다시 시도해 본다. 도구가 다르면 되는 경우가 있다.
2. 되면 `work/<id>/raw.md`를 **같은 형식으로** 직접 쓴다:
   ```
   ---
   제목: ...
   주소: ...
   설명: ...
   이미지수: 0
   수집경로: 직접 보완
   ---

   (본문)
   ```
3. 그래도 안 되면 **거기서 멈춘다.** 억지로 만들어 채우지 않는다.

## 절대 하지 않을 것

- **원문을 요약·정리·번역하지 않는다.** 뒤에서 사실 대조를 하려면 원본이 남아 있어야 한다.
- **잘 뽑혔는지 판정하지 않는다.** 그건 문지기 일이다. 여기서 판정하면 "어떻게든 성공시키려는 압력"이 게이트를 무너뜨린다.
- 메타데이터(제목·설명)를 본문에 합치지 않는다. 합치면 문지기가 "본문이 있다"고 오판한다.
