# 7. 발행 담당 (실행)

판단 기준 전문: [`agents/07-publisher.md`](../../agents/07-publisher.md)

## 절차

```bash
node scripts/publish.mjs --email    # out/newsletter.html
node scripts/publish.mjs --card     # out/cards.txt
```

`work/*/final.md`(없으면 `draft.md`)를 모아 분류별로 묶어 내보낸다. **내용은 바꾸지 않는다. 규격만 맞춘다.**

## 확인할 것

- **용량 경고가 뜨면 그냥 넘기지 마라.** 일정 크기를 넘으면 메일 서비스가 본문을 잘라낸다.
  줄일 곳은 불필요한 공백·주석부터다. 항목을 임의로 빼지 마라.
- **카드 장 나누는 지점은 사람에게 확인받는다.** 자동으로 4건씩 자르므로 문장이나 맥락 중간에서 끊길 수 있다.

## 이 에이전트가 다루지 않는 것

**채널 인증과 API 연동은 범위 밖이다.** 조직마다 쓰는 서비스가 다르고 인증 정보가 얽힌다.
여기서 하는 건 "확정 원고 → 채널이 받을 수 있는 형태"까지다. 그다음 한 걸음은 각자 채널 문서를 보고 붙인다.

새 채널을 추가한다면 **그 채널의 제약을 먼저 적고** 시작하라. 제약을 모르는 채로 변환하면 매번 손으로 고치게 된다.
